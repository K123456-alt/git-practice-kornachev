ШПАРГАЛКА ПО GIT
(лабораторная работа №2, github + VS Code)

НАСТРОЙКА
git config --global user.name "ваш_ник"
Указывает имя пользователя для подписи коммитов.
git config --global user.email "почта@example.com"
Указывает email для подписи коммитов.
git version
Проверка версии установленного Git.

СОЗДАНИЕ И ИНИЦИАЛИЗАЦИЯ
mkdir имя_папки
Создать папку проекта.
cd имя_папки
Перейти в папку.
git init -b main
Инициализировать локальный репозиторий с веткой main.
Создаёт скрытую папку .git.

БАЗОВЫЕ КОМАНДЫ
git status
Показать состояние репозитория (изменённые, новые файлы).
git add .
Добавить все изменения в индекс (staging area).
git add путь/к/файлу
Добавить конкретный файл в индекс.
git commit -m "сообщение"
Создать коммит с описанием изменений.
git log
Полная история коммитов.
git log --oneline
Компактная история (хеш + сообщение).
git show <хеш>
Детальная информация о конкретном коммите + diff.

ФАЙЛ .gitignore
.gitignore
Файл, в котором перечисляются файлы и папки,
игнорируемые Git.
Пример содержимого:
bin/
obj/
.vs/

РАБОТА С ВЕТКАМИ
git branch
Показать список локальных веток (* — текущая).
git branch -a
Показать все ветки, включая удалённые.
git switch -c имя_ветки
Создать ветку и переключиться на неё.
git switch имя_ветки
Переключиться на существующую ветку.
git switch -
Переключиться на предыдущую ветку.
git branch -d имя_ветки
Удалить ветку (безопасно, если изменения слиты).
git branch -D имя_ветки
Удалить ветку принудительно.

УДАЛЁННЫЙ РЕПОЗИТОРИЙ (GitFlic/GitHub)
git remote add origin <URL>
Привязать удалённый репозиторий с именем origin.
git remote -v
Показать адреса удалённых репозиториев (fetch/push).
git push -u origin main
Отправить ветку main на сервер и запомнить upstream.
git push --set-upstream origin feature
Отправить новую ветку feature и связать её с origin/feature.
git push
Отправить изменения (если upstream уже настроен).
git pull
Забрать изменения с сервера и слить с локальной веткой.
git fetch --prune
Обновить информацию об удалённых ветках
и удалить ссылки на несуществующие.

ПРОБЛЕМЫ И РЕШЕНИЯ
1) При git push появляется окно Git Credential Manager.
   Решение: ввести логин и пароль (или токен) от GitHub.
2) При git push ветки feature ошибка:
   "fatal: The current branch feature has no upstream branch."
   Решение: git push --set-upstream origin feature
